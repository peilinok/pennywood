# Feature Regression Matrix

IDs are stable contracts, not a count of screens. Never reuse an ID or silently remove a row. Mark deliberate replacements as superseded with a product decision and replacement ID. Link every behavior PR to affected IDs and add assertions for new cases. Test paths below identify existing coverage; they do not assert that a particular commit ran it.

`./scripts/check.sh` runs the entire host suite, including all 26 reference accounting cases. `./scripts/check-ios.sh` runs the isolated family-release flow and then a second process verifying persisted payments, debt, credentials, and child isolation, on disposable iPhone and iPad simulators. Those same targets also run the experience acceptance: schema5 upgrade/snapshot, shared agreements/rates, nested session, real loss, lesson playback, encrypted restore, and a second-process replay check. Other native flows above are additional manual/scheduled checks; CI does not claim to execute every integration file.
