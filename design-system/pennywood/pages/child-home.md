# Child Wish Page

Follow the [master design system](../MASTER.md). Order: child name/local-save state -> primary wish -> wish folder -> five quick tasks -> other actions.

iPhone is natural in portrait and also supports landscape. iPad reflows with orientation/window dimensions. Use sidebar only in sufficiently wide/tall windows; otherwise bottom navigation. Wide iPad windows should show five tasks in one row above the fold. Narrow windows use three columns, very narrow two, with vertical scrolling rather than smaller text/targets. Large text may push the task section down.

Wish progress uses confirmed accumulation, displaying target, confirmed amount, and gap. Never animate expected returns as owned money. Gift receipt and saving enough are separate. A funded gift still shows debt, and borrowing does not fill progress.

New wishes queue until explicit primary selection. Creation does not change cash. Real zero-onboarding should guide the first wish; never import the prototype's CNY 32.
